summary: 'Use a timer {child} can see, with warnings at set times, so the end of screen time is expected instead of sudden.'
why: 'Many children find time hard to feel. Seeing time run out makes the ending predictable, and predictable endings are calmer.'
sayThis: 'The timer is finished. Screen time is over.'
introduce: 'At a calm time, show {child} the timer and say: “This will tell us when screen time is nearly over. You will always get a warning first.”'
plan:
  calm: 'Choose a timer together (a kitchen timer, a sand timer or a phone timer {child} can see), and practise once in {place}.'
  ends: 'Start the timer when screen time starts. Give a warning when there are 5 minutes left. When it rings, say: “The timer is finished. Screen time is over.”'
  after: 'Move straight to {activity}, and thank {child} for stopping when the timer rang.'
consistency: 'Let the timer be the one who decides. When the rule belongs to the timer, there is less to argue about.'
obstacles:
  - title: 'Make the timer {child}’s helper'
    tip: 'Let {child} start the timer and choose where it stands. Children follow rules more easily when they help run them.'
  - title: 'If {child} asks for more time'
    tip: 'Answer once, kindly and the same way each time: “The timer decides. You can have screen time again tomorrow.”'
avoidWhen: 'If a ringing timer is upsetting for {child}, use a silent sand timer or a visual countdown with no sound.'
seekHelp: 'If ending screen time leads to very long or unsafe meltdowns most days, talk to a clinic, doctor, occupational therapist or psychologist.'

A countdown you can see makes the end of screen time predictable. The timer, not the parent,
says when it is over.
